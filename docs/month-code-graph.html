対応表

エッジの正体

次の月のコード = 今月のコード + (今月の日数 mod 7)。
31日 → +3 / 30日 → +2 / 2月(28日) → ±0。
12月→1月だけは 31日 (+3) なのに年が 365 日 (mod 7 = 1) 進むぶん -1 されて +2。
差分列: 3 0 3 2 3 2 3 3 2 3 2 2
※ 閏年は 1月・2月のみ -1 補正。

指標の見かた

隣接: 連続する月どうしが上下左右で隣り合っている本数 / 12。多いほど順路がなぞりやすい。
交差: 直線で描いたときのエッジ交差数。0 が理想。
同コード: 同じコードを持つ月ペアの平均距離 (セル単位, 1.00 が最小)。小さいほど同色が固まる。
総合 = 隣接率×100 − 交差×3 − (同コード−1)×8。
