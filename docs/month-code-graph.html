対応グラフの成分

「月 → その月のコード」を辺にすると 0-12 の 13 ノードの有向グラフになり、3 つの成分に分かれる。
0 に落ちる: 9・12 → 5 → 1 → 0 ← 10
3 の自己ループ: 8 → 2 → 3 ↻ ← 11
4 ⇄ 6 の相互ループ: 7 → 6 ⇄ 4
0 は「コードだけで月がない」唯一のノード。7-12 は月だけ、1-6 は月でもコードでもある。

指標の見かた

隣接: 12本のうち上下左右で隣り合っている辺の数 (自己ループを除く)。
交差: 直線で描いたときの辺の交差数。0 が理想。
辺長: 平均の辺の長さ (セル単位, 1.00 が最小)。
総合 = 隣接率×100 − 交差×4 − (辺長−1)×6。

矢印の意味

矢印は その月 → 翌月 で、ラベルは コードの増分 (例: 1月 c0 →+3→ 2月 c3)。
次の月のコード = 今月のコード + (今月の日数 mod 7)。
31日 → +3 / 30日 → +2 / 2月(28日) → ±0。
12月→1月だけは 31日 (+3) なのに年が 365 日 (mod 7 = 1) 進むぶん -1 されて +2。
差分列: 3 0 3 2 3 2 3 3 2 3 2 2
※ 閏年は 1月・2月のみ -1 補正。

指標の見かた

隣接: 連続する月どうしが上下左右で隣り合っている本数 / 12。多いほど順路がなぞりやすい。
交差: 直線で描いたときのエッジ交差数。0 が理想。
同コード: 同じコードを持つ月ペアの平均距離 (セル単位, 1.00 が最小)。小さいほど同色が固まる。
総合 = 隣接率×100 − 交差×3 − (同コード−1)×8。
