# 想起の研究メモ (記事ネタ)

3 桁 ⇔ かな辞書を「作る」ルール (採点: [scoring-rules-blog.md](./scoring-rules-blog.md)) とは別に、
「語から数字を**思い出せるか**」の観点で気づいたことを整理する。記事化前の下書き。

現行の採点 (`src/scorer.js`) は、はみ出したかなを種類に関係なく 1 文字 -1.0 (`overflowPerChar`) で一律に減点している。
以下はその一律扱いを見直す候補であり、どれもまだ採点には入れていない。

---

## 1. はみ出しても [ん] なら想起を邪魔しない (研究中)

- 語のかなが 3 桁を超える (`-a` 余り) とき、はみ出した部分が「ん」なら想起への影響が小さいという感覚がある。
- 「ん」は 0 の読みでもあるが、語末の「ん」は音として弱く、数字に変換するつもりで読む対象から自然に外れる。
- 論点: はみ出した [ん] を overflow の -1.0 から軽くする (例: -0.3) べきか。0 の読みと混同して 4 桁目と誤認しないか。

## 3. 未研究 (派生アイデア)

### 3-1. 読み方の網羅

- 1 つの語が複数の読みを持つ場合 (訓読み / 音読み / 愛称 / 略称など)、どれか 1 つでも 3 桁に届けば想起できる。
- 「読みが多いほど、どれかが想起される確率が上がる」とみなして、語の評価に足し込めるかもしれない。
- 未検討: 読みの候補をどう列挙するか、別の数字に当たる読みが混ざったときの混同をどう扱うか。

### 3-2. イントネーションの網羅

- 同じかなでもアクセント (高低) の違いで、思い出しやすさが変わる可能性がある。
- 読みの網羅をさらに一段広げ、イントネーションの候補ごとに当たりを持たせると、どれかが想起できる確率が上がるのではないか。
- 未検討: アクセントの情報源 (辞書データの有無)、評価にどう落とすか。

### 3-3. 余りが先頭の音の繰り返しになる型 (例: ルシェ{ル})

- 余り (`-a`) の型でも、はみ出した部分が語の先頭の音の繰り返しになっていると想起しやすい。
  - 例: 「ルシェル」 → 「ルシェ」で 3 桁を作り、末尾の {ル} は先頭の「ル」の繰り返し。
- 繰り返しは音として予測しやすいので、ただの余りより想起の評価を少し高くしてよいのでは、という仮説。
- 未検討: overflow の減点を軽くするのか、別途わずかに加点するのか。「先頭の繰り返し」以外の繰り返し (途中の音の繰り返し) も含めるか。

## 記事の構成案 (仮)

1. 作る採点と思い出す評価は別物 (現行は一律 overflow -1.0)
2. はみ出す [ん] / 途中の [ん]
3. 余りでも思い出しやすい型 (先頭の繰り返し)
4. 未研究: 読み方の網羅 → イントネーションの網羅 (どれかが当たる確率を上げる考え方)
