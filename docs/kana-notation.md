# よみ (かなセル) の記法

> D-0093 (D-0092 の書き方を改めた)。実装の正本は `src/kana-notation.js` (アプリの写しは `app/lib/kanaNotation.ts`)。

## 原則: 1 つの読み方には 1 通りの書き方だけ

よみは「どのかなを、何桁として読むか」を**書いた人が決めて、文字列に全部書く**データ。
encoder が「こう読めば番号に合う」と自動で探して通す規則は置かない。
字の種類 (ひらがな / カタカナ / 半角カナ) だけで意味が決まり、括弧などの囲みは使わない。

## 記法

| 書き方       | 意味                                                   | 例                              | 数字            |
| ------------ | ------------------------------------------------------ | ------------------------------- | --------------- |
| ひらがな     | 対応表どおりに読む                                     | すうる                          | 3376            |
| **カタカナ** | 2 桁を読むかなを 1 桁目だけで読む (半指定)             | スうる / よツは                 | 376 / 428       |
| **半角カナ** | 読まないかな                                           | さばﾝな / みっきｰ / きすﾏｰｸ     | 387             |
| **+ の後ろ** | 語尾 (3 桁を超えて数字にしない分)。ひらがな 2 文字まで | ひふみ+ん / とに+ーち / ひっ+ち | 123 / 102 / 122 |

- カタカナにできるのは対応表で 2 桁を読むかなだけ (つ=23 → ツ=2)。
- 拗音の半指定はまとめてカタカナ (チャ)。
- 半角カナは続けて書いてよい (ﾏｰｸ)。濁点は半角の ﾞ ﾟ を続ける (ｺﾞ)。
- 表示は書かれたままの字を出す。読む数字は添えない。半角カナは薄く出す。
- 語尾 (+ の後ろ) は D-0122。数字に関わらない語の残りを書く。rankey の余りの記号 (n / - / . / ..) が決まる 2 文字までで切る (トニーチョッパー = とに+ーち)。+ は 1 つで最後に置く。
- 語尾の頭の字は、直前の促音が写す数字になる (ヒッチ = ひっ+ち: っ が ち=22 を写す)。
- 語の括弧の中 (トイ(おもちゃ)) は語尾に書かない。

## 語尾 (3 桁を超えた分) は + の後ろに書く (D-0122)

よみは語の頭から読んで 3 桁に届く最短で止め、その後ろを + に続けてひらがな 2 文字まで書く
(キスマーク = きす+まー)。rankey はよみだけから余りを決め、語は見ない (+ が無いよみだけ語から数える)。
漢字の語は語尾が分からないので + を書かない (余りは不明)。
境界を跨ぐ 2 桁かな (たま=55|0) は読みの一部なので + の前に書く。

## 未決 (ユーザー判断)

- ~~語尾の書き足し~~: D-0122 で + の後ろに書くと決めた。nr kana:skip の tail (にいさﾝ) は使わない。
- **境界を跨ぐ 2 桁かな**: たま の ま を たマ と半指定で書かせるか (今は書かない。rankey の v)。
- **よみに書いてある語尾の余り**: ねおん=790 / のれん=750 は ねおﾝ / のれﾝ と書く方が正しい (ユーザー)。ろおま=600 は溢れのまま。どこまでを ﾝ にするか決まるまで自動では触らない。
- **伸ばし棒 ー の省略**: よみでは ー を う / い で書くことがある (ニュース=にゅうす → にゅｳす が正しい、バジーナ=ばじいな → ばじｲな は規則から外れる)。乳歯=にゅうし、喰種=ぐーる / ぐうる は揺れてよい。自動の restore は ー を戻さない。
- **中間省略**: どのかなを読まないかは自動で決めない (はっと=810 / ねおん=790 は頭 3 桁で合っていて省略ではない。つみれ=230 は つﾐれ とも ツみれ とも読める)。番号に合わないよみとして人が書く。
- 番号に合わない残り (ふぇい 291 / じぇし 694 など 22 件) は、対応表の不足・新しい読み方・よみの誤りに分けて別に扱う。

## 移行 (nr kana:canonical)

- 自動で揃えるのは、読み方が 1 つに決まるものだけ。既定は dry-run。
  - 半指定: 番号に合わないよみを、カタカナ 1 箇所で合わせられる候補がちょうど 1 つのとき (よつは → よツは)。中間省略でも合うよみは触らない
  - restore: 番号に合っているよみから消してある途中のかなを、語と突き合わせて戻す (ブロック: ぶろく → ぶろｯく)。ー は戻さない
  - カタカナの普通読み (パソ → ぱそ)、拗音 4 字 (じょﾝき)
- シートの check 列の式は別に書き直す (旧式のままだとカタカナ・半角カナを «不正» と出す)。
- DB (Firestore `numbers/*`) だけを書く。シートは sheetSync が反映する (D-0091)。
- かなを書き換えたら、同じ番号の代表 (`rep.picks`) と評価 (`ratings`) の `k` も新しいかなへ付け替える (`{k, w}` の完全一致で紐付いているため)。
