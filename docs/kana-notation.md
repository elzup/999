# よみ (かなセル) の記法

> D-0092。D-0062 / D-0090 / QA-0067 を一本化した。実装の正本は `src/kana-notation.js` (アプリの写しは `app/lib/kanaNotation.ts`)。

## 原則: 1 つの読み方には 1 通りの書き方だけ

よみは「どのかなを、何桁として読むか」を**書いた人が決めて、文字列に全部書く**データ。
encoder が「こう読めば番号に合う」と自動で探して通す規則は置かない。
自動で通ると、同じ読み方に書き方が複数でき (さばんな / さば(ん)な)、誤ったよみも黙って通る。

## 記法 (これ以外は書かない)

| 書き方 | 意味 | 例 | 数字 |
|---|---|---|---|
| ひらがな | 対応表どおりに読む | すうる | 3376 |
| **カタカナ** | 2 桁を読むかなを 1 桁目だけで読む (半指定) | スうる / よツは | 376 / 428 |
| **( )** | 読まないかな。ひらがな 1〜2 字と ー | さば(ん)な / みっき(ー) | 387 |

- カタカナにできるのは対応表で 2 桁を読むかなだけ (つ=23 → ツ=2)。1 桁のかなをカタカナにしたら不正。
- 拗音の半指定はまとめてカタカナ (チャ)。片方だけ (チゃ) は不正。
- 表示はカタカナの右肩に読む数字を添える (よツ²は)。( ) の中は薄く出す。
- `[つ]` 記法は廃止 (データ 0 件)。

## 不正にするもの (今は通っている)

| 今通る書き方 | なぜ一意でないか | 正しい書き方 |
|---|---|---|
| さばんな (自動の中間省略) | rankey が 1 字飛ばしを探して通す。さば(ん)な と同じ読み | さば(ん)な |
| じょんき (拗音 4 字の自動省略) | ん/う の省略が暗黙 | じょ(ん)き |
| さばな (読まないかなを消したよみ) | 語との対応が切れる | さば(ん)な |
| パソ (カタカナで普通に読む) | 半指定と区別がつかない | ぱそ |
| [つ] | カタカナと二重 | ツ |

## 語尾 (3 桁を超えた分) は書かない

よみは語の頭から読んで 3 桁に届く最短で止める (キスマーク = きす)。余りは rankey が語から数える。
削ると届かない溢れ (よっと / ぼむ / 末尾で境界を跨ぐ たま=55|0) はそのまま書く。

## 未決 (ユーザー判断)

- **語尾の ( ) 書き足し**: nr kana:skip の tail / restore は にいさ(ん) / きす(まー)(く) のように語尾を書き足すが、上の最短よみの規則と食い違う。どちらかに決めるまで nr kana:canonical は語尾に触らない。
- **境界を跨ぐ 2 桁かな**: たま の ま を たマ と半指定で書かせるか (今は書かない。rankey の v)。
- 番号に合わない残り (ふぇい 291 / じぇし 694 など 22 件) は、対応表の不足・新しい読み方・よみの誤りに分けて別に扱う。

## 移行 (nr kana:canonical)

- 半指定 / 途中の ( ) / 拗音 4 字 / カタカナの普通読み を揃える。既定は dry-run。
- DB (Firestore `numbers/*`) だけを書く。シートは sheetSync が反映する (D-0091)。
- かなを書き換えたら、同じ番号の代表 (`rep.picks`) と評価 (`ratings`) の `k` も新しいかなへ付け替える (`{k, w}` の完全一致で紐付いているため)。
